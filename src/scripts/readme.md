# Структура файлов
## accordion.js
Файл реализует функциональность выпадающего меню/списка (accordion), используемого на главной странице сайта. Обеспечивает возможность открытия и закрытия секций с информацией простым кликом мыши.

## data.js
Этот файл хранит данные, используемые проектом — названия категорий, элементы списков, тексты кнопок и прочие статические данные, передаваемые компонентам интерфейса.

## feedback-form.js
Реализует форму обратной связи, доступную на всех страницах приложения, включая версию в виде всплывающего окна (pop-up). Файл управляет обработкой отправки сообщений и интеграцией формы с сервером приложений.

## popup.js
Класс, предназначенный для управления отображением и закрытием модальных окон («поп-ап»). Используется совместно с формой обратной связи и другими элементами страницы, которым необходим механизм показа-вывода на передний план.

## range-slider.js
Инициализирует диапазонный ползунок (slider) на формах фильтров. Позволяет пользователям выбирать числовой интервал значений посредством графического компонента.

## swiper-factory.js
Создает экземпляры слайдеров (каруселей изображений), используя настройки из файла data.js. Реализован как фабричный метод, позволяющий легко создавать различные типы слайдеров с индивидуализированными параметрами.

## utils.js
Сборник вспомогательных функций, необходимых для общего функционирования приложения. Включает методы проверки валидности форм, обработки ошибок и другие часто используемые операции.

## yandex-map.js
Занимается инициализацией Яндекс.Карты на странице контактов. Содержит код, ответственный за подключение API карт Яндекса и размещение маркеров с адресами организации.
